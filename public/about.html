About Me!

<p>I am a Front-end Architect from Chennai, India. I work for a company called <a href="https://www.caterpillar.com/en/company.html">Caterpillar</a> as a Principal Software Engineer where we build <a href="https://digital.cat.com/">awesome products</a> for the the world’s leading manufacturer of construction and mining equipment, off-highway diesel and natural gas engines, industrial gas turbines and diesel-electric locomotives.</p>

<p>I love books, art, music and movies. I used to be a <a href="https://www.deviantart.com/rajasegar">Graphic Designer</a> and Systems Programmer once.</p> <p>I love programming languages like <a href="https://developer.mozilla.org/en-US/docs/Web/JavaScript">Javascript</a>, <a href="https://www.ruby-lang.org/en/">Ruby</a>, <a href="https://www.haskell.org/">Haskell</a> and <a href="https://en.wikipedia.org/wiki/Lisp_(programming_language)">Lisp</a>. I wholeheartedly embrace Functional Programming, Code clarity, Performance, Accessibility and Internationalization.</p> <p>I am passionate about Open Source Software and Contributions, recently, I have been writing tools in JS</p> <p>I write code in <a href="https://emberjs.com">Ember.js</a> and <a href="https://reactjs.org">React.js</a></p> <p>My favorite editors are <a href="https://www.gnu.org/software/emacs/">Emacs</a> and <a href="https://www.vim.org/">Vim</a> (in order of preference)</p>
